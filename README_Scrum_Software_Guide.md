# Scrum Software for a Company - Guide

## Shortlist by company type
- **Engineering-focused, mid to large:** Jira, Azure DevOps
- **Startup / product-led team:** Linear, YouTrack
- **Mixed business and tech teams:** ClickUp, monday.dev, Asana
- **Code already on GitHub/GitLab:** GitHub Projects or GitLab Issues
- **Many teams / SAFe:** Jira Align, Planview, Azure DevOps portfolio features

## How to choose
1. Team size: under ~15 people, a lighter tool is usually enough.
2. Existing stack: match your repos, chat (Slack/Teams) and CI/CD.
3. Users: engineering-only vs. mixed business and tech teams.
4. Reporting: velocity, burndown and cross-team views.
5. Compliance: GDPR, EU hosting, or self-hosting (GitLab, Jira Data Center, YouTrack).
6. Cost: per-user pricing adds up; check current plans before deciding.

## Recommended process
Shortlist two tools, then pilot both with one real team for one or two sprints.
Use the workbook: `Scrum_Tool_Comparison.xlsx`
- **Tool Overview** - side-by-side summary
- **Scoring Matrix** - adjust weights and scores (blue cells); totals and ranks recalculate
- **Pilot Checklist** - steps from shortlist to decision

Note: scores are general estimates. Verify features and pricing with vendors.
